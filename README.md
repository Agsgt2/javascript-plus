# javascript-plus
javascript made easier and complicated at the same time
## Use
To use this "library", you can add the following line of code below:
```js
import * as jsp from "https://raw.githubusercontent.com/Agsgt2/javascript-plus/refs/heads/main/script.mjs"
```
## Print
To print anything to the console in javascript+, you may use the `print` function.
```js
print("Hello, World!")
```
## Arrays
To define a array, you may use the `defineArray` function
```js
const a = defineArray(2, 3, 4)
print(a) // [2, 3, 4]
```
## `is-thirteen` support
